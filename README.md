# Create: Wrench Guard

Adds configurable allow, warning-confirmation, deny, and inventory-capacity rules to Create wrench removal.

## Requirements

Minecraft 1.21.1, NeoForge 21.1.219 or newer, and Cloth Config API 15.0.140 or newer, plus Create 6.0.11 or newer.

## Installation side

Client and server - required on both.

## Configuration

Configuration is available through the Cloth Config screen and is persisted in the instance's config directory.

## Development

Source code for NeoForge 1.21.1 is maintained on the 
eoforge/1.21.1 branch. This documentation-only branch intentionally contains no mod source code.
